# 📊 Dashboard de Vendas — Superstore 2015-2018

Dashboard interativo desenvolvido no Excel como parte do meu aprendizado em Análise de Dados.
Os dados utilizados são do dataset público **Superstore Sales** disponível no Kaggle.

---

## 🎯 Objetivo

Consolidar as análises do projeto em um único painel visual, respondendo 3 perguntas de negócio de forma clara e direta:

1. Qual categoria de produto mais vendeu?
2. Qual mês teve maior receita?
3. Qual região tem o maior ticket médio por pedido?

---

## 🛠️ Ferramentas utilizadas

- Microsoft Excel
- Tabelas Dinâmicas
- Gráficos Dinâmicos
- Formatação e Design de Dashboard

---

## 📊 O Dashboard

O painel reúne em uma única tela:

- **3 cards de destaque** com os principais resultados
- **Gráfico de barras** — vendas por categoria
- **Gráfico de linha** — evolução da receita ao longo dos anos
- **Gráfico de barras horizontais** — ticket médio por região

---

## 💡 Principais Insights

| | Pergunta | Resposta |
|---|---|---|
| 🏆 | Categoria top | **Furniture** |
| 📅 | Mês de maior receita | **Novembro de 2018** |
| 📍 | Maior ticket médio | **Região Central** |

- **Furniture** lidera em receita, sendo a categoria mais estratégica da loja
- O pico em **novembro** coincide com a Black Friday — forte dependência de sazonalidade
- A região **Central** tem clientes com maior valor médio por pedido, mesmo com menor volume total que a West
